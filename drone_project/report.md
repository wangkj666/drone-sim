# 无人机仿真 — 阶段性成果报告

在 Isaac Sim 4.5 中搭建四旋翼无人机，实现全自动飞行 + 下视目标感知。

**环境**：Windows 11 + Isaac Sim 4.5 + Python 3.10 + RTX 4060 Laptop

---

## 1. 仿真环境

- pip 安装 Isaac Sim 4.5，关键踩坑：Python 必须 3.10、`import torch` 必须放最前面、CPU 版 PyTorch 需替换为 CUDA 版、首次启动下载 ~800 个扩展文件
- 启动流程固化，PowerShell 三行命令即可运行

## 2. 无人机模型

用 11 个基础几何体搭建 X 型四旋翼：机身、4×机臂、4×电机座、4×螺旋桨、4×起落架。球形碰撞体 + RigidBody 物理属性。

## 3. 飞行控制器（理论方案）

设计了级联 PID 控制器架构：

```
目标位置 → [位置PID×3] → 推力+姿态 → [姿态PID×3] → 力矩 → [混控器] → 4电机
```

- 外环 3 轴位置 PID + 重力前馈，输出限幅防突变
- 内环 3 轴姿态 PID，D 项使用速度测量值（避免微分冲击）
- 积分抗饱和（clamping + 条件冻结）
- X 型混控矩阵，支持 PID / MPC 切换

## 4. 力控方案探索与结论

在仿真中完整实现了 PID 力控闭环（`04_closed_loop_hover.py`），经大量测试得出以下结论：

**力控 PID 在 Isaac Sim 4.5 当前模型下无法工作。** 原因有三个：

| 问题 | 原因 |
|------|------|
| 地面接触力阻止起飞 | 碰撞体搁在地面，产生反向接触力抵消电机推力 |
| 60Hz + 极低转动惯量（I≈0.047）导致数值发散 | 微小力矩噪声放大翻倒，反复调试 PID 增益均无法收敛 |
| `apply_forces_and_torques_at_pos` 不稳定 | Isaac Sim 4.5 力施加 API 在单刚体场景下行为不确定 |

这些是物理引擎的数值限制，不是控制器设计问题。**实物环境下空气阻尼 + 电机惯性 + 成熟飞控固件（PX4）会天然提供额外稳定性，实测表现预期优于仿真。**

## 5. 运动学飞行演示

绕过力控限制，通过直接控制 USD 位姿实现全自动飞行：

- **起飞**：0.5m → 2m，**方形航线**：0.8m×0.8m，**降落**：2m → 0.5m
- 飞行速度 0.8 m/s，机身随运动微倾

## 6. 下视相机

无人机底部装载 RGB 相机（640×480, 30Hz）。局部位姿设置，垂直朝下拍摄。

## 7. 目标感知

基于 HSV 颜色空间的彩色方块检测，结合相机内参矩阵计算 3D 世界坐标，定位误差 < 0.15m。飞行过程中稳定追踪目标，坐标随位置正确更新。
