# 无人机仿真 — 阶段性成果报告

在 Isaac Sim 4.5 中搭建四旋翼无人机，实现全自动飞行 + 下视目标感知。

**环境**：Windows 11 + Isaac Sim 4.5 + Python 3.10 + RTX 4060 Laptop

---

## 1. 仿真环境

- pip 安装 Isaac Sim 4.5，关键踩坑：Python 必须 3.10、`import torch` 必须放最前面、CPU 版 PyTorch 需替换为 CUDA 版、首次启动下载 ~800 个扩展文件
- 启动流程固化，PowerShell 三行命令即可运行

## 2. 无人机模型

用 11 个基础几何体搭建 X 型四旋翼：机身、4×机臂、4×电机座、4×螺旋桨、4×起落架。球形碰撞体 + RigidBody 物理属性。

## 3. 飞行控制器（理论方案）

设计了级联 PID 控制器架构：

```
目标位置 → [位置PID×3] → 推力+姿态 → [姿态PID×3] → 力矩 → [混控器] → 4电机
```

外环 3 轴位置 PID + 重力前馈，内环 3 轴姿态 PID，X 型混控矩阵。在仿真中实测发现：60Hz + 极低转动惯量（I≈0.047）导致力控不稳定——微小的力矩噪声即被放大翻倒。这是物理引擎的数值限制。

## 4. 运动学飞行演示

改用 USD API 直接控制位姿，实现全自动飞行：

- **起飞**：0.5m → 2m，**方形航线**：0.8m×0.8m，**降落**：2m → 0.5m
- 飞行速度 0.8 m/s，机身随运动微倾

## 5. 下视相机

无人机底部装载 RGB 相机（640×480, 30Hz）。使用 `isaacsim.sensors.camera` + USD Xform 局部位姿，无需旋转即可垂直朝下拍摄。实时保存俯视图像。

## 6. 目标感知

基于 HSV 颜色空间的彩色方块检测，结合相机内参矩阵计算 3D 世界坐标：

| 方块 | 实际位置 | 检测位置 | 误差 |
|------|---------|---------|------|
| 红色 | (-0.4, -0.4) | (-0.33, -0.28) | ~0.1m |
| 绿色 | (0.4, -0.4) | (0.33, -0.28) | ~0.1m |
| 蓝色 | (-0.4, 0.4) | (-0.33, 0.28) | ~0.1m |
| 黄色 | (0.4, 0.4) | (0.33, 0.28) | ~0.1m |

无人机飞行过程中能稳定追踪目标，坐标随位置正确更新。
