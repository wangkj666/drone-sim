### 4. 全自动飞行演示
- USD 运动学控制，实现起飞→方形航线→降落
- 飞行速度 0.8 m/s，高度保持 ±0.05m，机身随运动方向微倾

### 5. 下视相机 + 目标感知
- 无人机底部 RGB 相机（640×480，30Hz），垂直朝下拍摄
- HSV 颜色检测 + 相机内参 → 3D 世界坐标
- 定位误差 < 0.15m（实测 4cm），飞行中稳定追踪

### 6. 自主目标接近（感知闭环）
- 感知检测目标 → 坐标传给飞控 → 自动飞过去 → 悬停在上方
- 实测流程：起飞 2.5m → 检测红色方块 (-0.49, 0.00) → 飞至目标正上方 → 降至 0.6m

## 9. 夹爪机构重做 + 仿真基础问题排查

### 9.1 按结构图重做夹爪

```
    (  [机身]  )      ← 左右各一条弯齿条, 齿在内侧, 像括号夹住机身
       ╲  ╱
        ●             ← 中心连杆 + 关节
```

- **弯齿条**：曲率半径 0.17m，各 12 段 + 12 齿，齿在凹面（朝中间）
- **驱动**：机身正下方舵机盒 + 两个互相啮合的齿轮（各 12 齿）
- **连杆**：随臂运动，中心汇合到关节（对应结构图的红点）
- **朝下抓取**：尖端间距 0.096m（夹紧）/ 0.223m（张开），下探 0.17m
- **朝上抓取**：整组翻转 130°，尖端到机身上方 +0.16m

参数不是估的，是**扫描角度测出来的**——测出 0.096m 间距刚好夹住 0.10m 的目标。

### 9.2 排查出的建模 Bug（这批问题很隐蔽）

| 问题 | 现象 | 原因 |
|------|------|------|
| **机臂消失** | 桨叶看着像浮在空中的白条 | `create_prim` 后再追加旋转，USD 的 op 顺序导致**先旋转再缩放**，机臂被压成薄片。需先把 rotate 排在 scale 之前 |
| **无人机渲染位置错误** | 物体总在无人机"上方" | 无人机带 RigidBody 但由 USD 坐标驱动 → **渲染跟物理走，不跟 USD 走**。增加 kinematic 模式（不加刚体）解决 |
| **子零件整体偏移 0.5m** | 机身与实际位置差半米 | `create_prim` 的 `position` 按**世界坐标**处理，会补偿父节点变换；改为先把根节点建在原点 |
| **低空检测不到目标** | 降到 1.5m 后相机看不到方块 | 相机默认 50mm 长焦，**水平视角仅 23.7°**；改成按目标视角反算焦距（80°广角） |
| **目标定位偏 7cm** | 检测坐标系统性偏大 | 测距用了无人机高度，没扣掉**相机下沉 0.15m** 和**目标自身高度 0.14m**；修正后误差为 0 |

### 9.3 外观问题

- 桨叶下降 6mm 坐在电机上（原先悬空 6mm）
- 夹爪两侧加**支架 + 转轴**连到机身
- 齿轮移到机身正中下方，两轮啮合
- 机身/桨叶尺寸修正（原先按 ±1 立方体算，实际尺寸是 2 倍）
